# Coral Reefs figure delivery package

Each numbered figure is supplied as a vector PDF (the preferred file for line
art) and a 600-dpi LZW-compressed TIFF fallback. All figures are double-column
width (174 mm); heights are 175 mm (Fig. 1), 220 mm (Fig. 2), 230 mm (Fig. 3),
and 180 mm (Fig. 4), below the journal's 234-mm maximum. Figure legends remain
in the manuscript as a separate list, as required by *Coral Reefs*.

The TIFFs are rasterized directly from the vector PDFs rather than upsampled
from PNG review images.
