# Methods — Restoration Scenario Explorer (RSE) Modeling Paper

## Population model

We built a 5-class Lefkovitch projection matrix **A** for *Acropora palmata* with size classes SC1–SC5 bounded by 0, 10, 100, 900, 4,000 cm² and ∞ live planar tissue area (after Vardi et al. 2012). Each annual time step,

> **A = G · diag(S) + F<sub>frag</sub> + F<sub>sex</sub>**

where **G** is the 5 × 5 size-class transition matrix, **S** is the size-specific annual survival vector, **F<sub>frag</sub>** is the fragmentation-derived asexual recruitment matrix (Vardi 2011 fragmentation data), and **F<sub>sex</sub>** is a size-threshold sexual fecundity matrix activated for scenario comparisons. The deterministic population growth rate λ = |Re(eigen(A)$values[1])| is supplemented with stage-structured elasticity, bootstrap 95% confidence intervals, quasi-extinction time, and stochastic Tuljapurkar λ<sub>s</sub> approximations.

## Parameter estimation from the synthesis

Parameters for the RSE are packaged as context-stratified RDS files in `parameter_lists/` and regenerated by `06_analysis/scripts/17_update_parameter_lists.R`. Three contexts are distinguished to match RSE restoration pathways:

1. **Field (natural colonies).** Annual survival per size class is pooled via a study-level random-effects meta-analysis (`metafor::rma`, REML, Knapp–Hartung adjustment) on cell-aggregated (study × size class) effects drawn from 17 studies and 22 effects (`prepared_survival_cells.rds`). Growth is estimated from 4,994 natural-colony growth records (`fragment == "N"`) across three individual-level studies (NOAA_survey, neely_et_al_2022, mendoza_quiroz_et_al_2023). Fragmentation events are explicitly excluded from the field growth matrix; they enter the model through **F<sub>frag</sub>**.

2. **Nursery / outplanted fragments.** Survival is pooled over 3,277 cell-level observations from 11 studies that contributed restoration-fragment data, using the same cell-weighted `rma()` approach. Growth is estimated from 901 fragment-origin records (`fragment == "Y"`) across five studies (fundemar_fragments, kuffner_et_al_2020, NOAA_survey fragment subset, pausch_et_al_2018, USGS_USVI_exp).

3. **Post-settlement recruits.** A separate `recruit_surv_pars.rds` object carries per-oocyte → SC1 annualized survival estimated from 16,479 recruit-tracked observations across three studies (chamberland_et_al_2015, fundemar_recruits, mendoza_quiroz_et_al_2023). Mean s<sub>recruit</sub> = 0.027 (95% CI: 0.009–0.104). This quantity is exposed as an alternative to the RSE's hard-coded `s1` nursery-fragment survival for larval-propagation scenarios.

All parameter distributions are generated with a **2,000-iteration hierarchical cluster bootstrap** (studies → observations within studies). This matches the resolution used by the deterministic transition matrix (script 13) so parameter uncertainty is identically represented in both the baseline analysis and the RSE.

## Scenario framework

The RSE exposes three scenario families, each grounded in the literature-sourced biological-realism framework described in `07_reporting/internal/biological_realism_PRD.md` (scripts 50–61):

- **Chronic baseline.** Field survival and growth as estimated above; F<sub>sex</sub> = 0; λ = 0.961 (pre-2023 Caribbean baseline).
- **Acute heatwave overlay (Manzello 2025).** DHW dose–response mortality applied as a multiplicative survival modifier to reproduce the 2023 Florida functional extinction signal (97.8–100% mortality at 16–20 DHW; script 40).
- **Biological-realism toggles.** Nine named scenarios (S0–S8) toggle sexual fecundity (Vardi 2011 size threshold × Mendoza-Quiroz 2023 oocyte density), 4-year post-disturbance sterility (Lirman 2000a), lesioned-colony fecundity penalty (Piñón-González 2018), outplant-age survival decay (Boisvert 2024), winter-SST × size disease interaction (NOAA ERSST v5 anomalies × Rodriguez-Martinez 2014), depensatory corallivory (Williams 2012), and microhabitat depth refugia.

Sexual recruitment uses a settlement-efficiency rescaling of Chamberland 2015 (SETTLEMENT_EFFICIENCY = 1 × 10⁻⁴) to match wild Caribbean broadcast-spawning rates; this is the single parameter that is not literal-from-literature.

## Size-class S0 anchoring

The RSE reproduces the published deterministic baseline λ = 0.9613 exactly by reusing the canonical `growth_transitions` from `transition_matrix.rds` via the `G_override` argument of `compute_lambda_from_survival()` (utils/03_matrix_functions.R). Growth transitions computed from the live CSV panel differ slightly due to post-publication data accretion; the override ensures the RSE is anchored to the manuscript's validated matrix.

## Web platform

The interactive front end lives in a separate repository (`stier-lab/Detmer-2025-coral-platform`) as a React + TypeScript application backed by an R Plumber API that loads the `parameter_lists/*.rds` files and exposes endpoints for λ, elasticity, quasi-extinction time, and size-class trajectories under user-specified scenarios. The API is a thin wrapper around `compute_lambda_from_survival()` and `run_scenario()` so any rerun of script 17 flows directly into the platform without manual intermediate steps.

## Software and reproducibility

All analyses use R ≥ 4.3 with `metafor` (meta-analysis), `mgcv` (GAMs), `lme4`/`lmerTest` (GLMMs), `popbio` (elasticity), `rerddap` (NOAA ERSST v5 queries), `patchwork`/`ggplot2` (figures). The full pipeline is orchestrated by `06_analysis/scripts/run_all.R`; parameter regeneration for the RSE takes ~15 minutes on a 2023-era laptop. Code, data, and derived parameter distributions are archived at `github.com/stier-lab/Detmer-2025-coral-parameters` (this repo) and `github.com/stier-lab/Detmer-2025-coral-platform` (web tool).
