## Core Results

### Core Nonlinearity Outputs

The threshold and curvature analyses are part of the main analytical framework. The main files are:

- `survival_thresholds.csv`
- `survival_threshold_models.rds`
- `growth_thresholds.csv`
- `growth_threshold_models.rds`
- `temporal_nonlinearity_test.csv`

The first four come from the size-threshold workflow (`02`, `03`, `25`). The temporal file comes from `08_climate_demography.R` and should be interpreted separately from the size-threshold analyses.

---

### survival_thresholds.csv
**Generated by:** `02_survival_thresholds.R`

Size thresholds for survival probability changes.

| Column | Description |
|--------|-------------|
| `analysis` | Analysis type (e.g., "Overall Survival") |
| `method` | Detection method (GAM_second_derivative) |
| `threshold_log` | Log-transformed threshold value |
| `threshold_cm2` | Threshold in cm² |
| `max_curvature` | Maximum second derivative |
| `shape` | Relationship shape (ABRUPT, GRADUAL) |
| `cluster_boot_mean/median/se` | Bootstrap statistics |
| `cluster_boot_ci_lower/upper` | 95% confidence interval |
| `cluster_boot_cv` | Coefficient of variation |
| `loso_min/max` | Leave-one-study-out range |
| `n_observations/studies/locations/years` | Sample metadata |

**Current interpretation:** Survival shows a supported nonlinear, sigmoidal size relationship, but the survival threshold is weakly stable. The current recommended inflection is ~7,498 cm², with broad leave-one-study-out uncertainty.

---

### growth_thresholds.csv
**Generated by:** `03_growth_thresholds.R`

Size thresholds for growth rate changes.

| Column | Description |
|--------|-------------|
| `response` | Response variable (absolute_growth, relative_growth_rate, positive_growth_prob) |
| `threshold_log/cm2` | Threshold values |
| `max_curvature` | Maximum curvature |
| `cluster_boot_ci_lower/upper` | Bootstrap confidence interval |
| `cluster_boot_cv` | Coefficient of variation |
| `n_observations` | Sample size |
| `r_squared` | Model R² |

**Current interpretation:** Relative growth rate is the clearest nonlinear growth metric. The current recommended RGR threshold is ~36.9 cm², and RGR explains 21.7% of variance, about 5.3x more than AGR.

---

### temporal_nonlinearity_test.csv
**Generated by:** `08_climate_demography.R`

Likelihood-ratio comparison of linear vs quadratic temporal trend models.

**Current interpretation:** The time-series surface also shows evidence of nonlinearity (`lrt_p = 0.019`), but this file is conceptually separate from the size-threshold analyses above.

## Advanced Dynamic Model Extensions

The advanced-model layer extends the project beyond standard GLMMs and the static transition matrix. These files are organized by prefix and come from scripts `41`--`47`.

### `multistate_*`
**Generated by:** `41_multistate_transition_model.R`

Annualized size-class transition matrices, state-specific death predictions, and retrogression summaries for a `SC1`--`SC5 + Dead` multistate system.

### `joint_longitudinal_*`
**Generated by:** `42_joint_longitudinal_survival_model.R`

Two-stage joint longitudinal-survival approximation linking colony live-size trajectories to interval mortality risk. Includes fit metrics, calibration, and risk predictions.

### `stochastic_ipm_*`
**Generated by:** `43_stochastic_ipm_disturbance_model.R`

Regime-conditioned integral-projection-model approximations and stochastic viability summaries under observed disturbance regimes.

### `regime_switching_*`
**Generated by:** `44_regime_switching_model.R`

Hidden-state year classifications and transition matrices for demographic regimes inferred from annual survival-condition deviations.

### `distributed_lag_*`
**Generated by:** `45_distributed_lag_disturbance_model.R`

Region-year lag histories, model comparison tables, coefficient summaries, and prediction grids for lagged disturbance effects on survival and growth.

### `recurrent_event_*`
**Generated by:** `46_recurrent_event_frailty_model.R`

Colony-history recurrent-event panels plus frailty-model summaries for repeated shrinkage and terminal mortality.

### `spatiotemporal_*`
**Generated by:** `47_spatiotemporal_hierarchical_model.R`

Spatiotemporal hierarchical summaries over site coordinates and site-year structure. The current script runs both a survival model and a positive-growth model; see `spatiotemporal_survival_model_comparison.csv` and `spatiotemporal_growth_model_comparison.csv`.

---

### transition_matrix.csv
**Generated by:** `13_transition_matrix.R`

Lefkovitch population projection matrix (5×5).

| Row/Column | Description |
|------------|-------------|
| SC1_recruit | 0-10 cm² |
| SC2_small_juv | 10-100 cm² |
| SC3_large_juv | 100-900 cm² |
| SC4_subadult | 900-4000 cm² |
| SC5_adult | >4000 cm² |

Matrix element (i,j) = probability of transitioning from size class j to size class i.

**Key finding:** `lambda = 0.967` (95% bootstrap interval: `0.828-1.059`), indicating that decline is more likely than growth in the current synthesis, but uncertainty still spans both outcomes.

---

### elasticity_matrix.csv
**Generated by:** `13_transition_matrix.R`

Proportional sensitivity of λ to each matrix element.

**Key finding:** SC5 stasis (staying large) remains the dominant matrix-cell elasticity (`57.4%`), and aggregated SC5 survival elasticity is `58.8%`.

---

### variance_partitioning.csv
**Generated by:** `05_variance_partitioning.R`

Pseudo-R² and AIC for nested survival models.

| Model | Components |
|-------|------------|
| Size only | Size class effect |
| Region only | Geographic region effect |
| Year only | Temporal trend |
| Size + Region | Combined effects |
| Full | Size + Region + Year |

**Key finding:** Size explains 8.0%, Region 1.3%, Time 3.9% of variance
