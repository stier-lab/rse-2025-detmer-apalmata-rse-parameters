# Analysis Output Files

This directory contains results from the *Acropora palmata* demographic analysis pipeline. Files are organized by analysis type and generated by scripts in `analysis/scripts/`.

## Overview

| Category | Files | Description |
|----------|-------|-------------|
| Thresholds | 2 | Size-dependent survival and growth thresholds |
| Variance | 2 | Variance partitioning results |
| Population Model | 2 | Transition matrices and elasticities |
| Meta-analysis | 7 | Study-level effect sizes and pooled estimates |
| Data Quality | 8 | Certainty scores, gaps, and diagnostics |
| Model Selection | 6 | Model comparison and coefficients |
| Sensitivity | 7 | Robustness checks |
| Power Analysis | 3 | Sample size requirements |
| Context Comparison | 7 | Field vs. nursery vs. lab comparisons |
| Summary Statistics | 8 | Descriptive summaries by region/size/year |
| Cross-validation | 3 | Out-of-sample validation results |

## Core Results

### survival_thresholds.csv
**Generated by:** `02_survival_thresholds.R`

Size thresholds for survival probability changes.

| Column | Description |
|--------|-------------|
| `analysis` | Analysis type (e.g., "Overall Survival") |
| `method` | Detection method (GAM_second_derivative) |
| `threshold_log` | Log-transformed threshold value |
| `threshold_cm2` | Threshold in cm² |
| `max_curvature` | Maximum second derivative |
| `shape` | Relationship shape (ABRUPT, GRADUAL) |
| `cluster_boot_mean/median/se` | Bootstrap statistics |
| `cluster_boot_ci_lower/upper` | 95% confidence interval |
| `cluster_boot_cv` | Coefficient of variation |
| `loso_min/max` | Leave-one-study-out range |
| `n_observations/studies/locations/years` | Sample metadata |

**Key finding:** Threshold ~26,000 cm² but 95% CI spans 1-26,000 cm² (high uncertainty)

---

### growth_thresholds.csv
**Generated by:** `03_growth_thresholds.R`

Size thresholds for growth rate changes.

| Column | Description |
|--------|-------------|
| `response` | Response variable (absolute_growth, relative_growth_rate, positive_growth_prob) |
| `threshold_log/cm2` | Threshold values |
| `max_curvature` | Maximum curvature |
| `cluster_boot_ci_lower/upper` | Bootstrap confidence interval |
| `cluster_boot_cv` | Coefficient of variation |
| `n_observations` | Sample size |
| `r_squared` | Model R² |

**Key finding:** Relative growth rate explains 33.9% of variance (vs 1% for absolute growth)

---

### transition_matrix.csv
**Generated by:** `13_transition_matrix.R`

Lefkovitch population projection matrix (5×5).

| Row/Column | Description |
|------------|-------------|
| SC1_recruit | 0-10 cm² |
| SC2_small_juv | 10-100 cm² |
| SC3_large_juv | 100-900 cm² |
| SC4_subadult | 900-4000 cm² |
| SC5_adult | >4000 cm² |

Matrix element (i,j) = probability of transitioning from size class j to size class i.

**Key finding:** λ = 0.986 (95% CI: 0.819-1.020), indicating ~1.4% annual decline

---

### elasticity_matrix.csv
**Generated by:** `13_transition_matrix.R`

Proportional sensitivity of λ to each matrix element.

**Key finding:** SC5 stasis (staying large) has highest elasticity (54.8%)

---

### variance_partitioning.csv
**Generated by:** `05_variance_partitioning.R`

Pseudo-R² and AIC for nested survival models.

| Model | Components |
|-------|------------|
| Size only | Size class effect |
| Region only | Geographic region effect |
| Year only | Temporal trend |
| Size + Region | Combined effects |
| Full | Size + Region + Year |

**Key finding:** Size explains 8.0%, Region 1.3%, Time 3.9% of variance

## File Naming Convention

- `*_summary.csv` - Aggregated statistics
- `*_by_*.csv` - Stratified by variable
- `*_comparison.csv` - Statistical comparisons
- `*_sensitivity.csv` - Sensitivity analysis results
- `*_diagnostics.csv` - Model diagnostic metrics
- `*_stratified.csv` - Stratified analyses

## Regenerating Outputs
